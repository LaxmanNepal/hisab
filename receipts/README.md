# Receipt images

Upload receipt scans or photos here. Multiple files for the same date are supported.

Use date-first filenames, for example:

- `2026-10-30-receipt-01.jpg`
- `2026-10-30-receipt-02.jpg`
- `2026-10-30-receipt-03.png`

The website automatically groups all image files by date. Do not upload confidential or personal customer information to this public repository.
