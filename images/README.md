# Daily supporting images

Upload JPG, JPEG, PNG, WEBP, GIF or AVIF files here.

Include the date in each filename so the public gallery groups files by day, for example:

- `2026-10-30-voucher-01.jpg`
- `2026-10-30-bank-slip-02.png`

The website automatically lists image files in this folder and groups them by date. Do not upload confidential or personal customer information to this public repository.
